# Лабораторная работа №4: Ленивые последовательности и Машина Тьюринга
В рамках данной лабораторной работы реализована концепция абстрактных полиморфных типов данных (АТД) на языке C++. Основными задачами являлись:
1. Разработка и реализация АТД `LazySequence<T>` (ленивой последовательности)
2. Реализация отложенных операций трансформации и фильтрации данных (`Map`, `Where`, `Concat` и др.)
3. Применение разработанных АТД для решения прикладной тематической задачи — эмулятора **Машины Тьюринга** с бесконечной в обе стороны лентой
4. Покрытие разработанных алгоритмов модульными тестами и оснащение программы интерактивным пользовательским интерфейсом.

---

## Структура проекта и архитектура
* `sequence.h` — базовый абстрактный класс (интерфейс) для всех последовательностей.
* `array_sequence.h` — базовая, а также изменяемая (`MutableArraySequence`) и неизменяемая (`ImmutableArraySequence`) реализации на основе динамического массива
* `dynamic_array.h` — низкоуровневый шаблонный динамический массив
* `lazy_sequence.h` — класс ленивой последовательности с поддержкой мемоизации
* `lazy_rules.h` — классы конкретных правил генерации элементов (`ConstantRule`, `MapRule`, `WhereRule`, `ConcatRule`, `ModifyRule`, `AppendRule`)
* `generator.h`, `igenerator_rule.h` — абстракции генератора и инкапсулированных правил для пошагового вычисления элементов
* `turing_machine.h` — управляющий логический блок Машины Тьюринга
* `turing_tape.h` — реализация двунаправленной бесконечной ленты
* `main.cpp` — консольное интерактивное меню программы
* `tests.cpp`, `tests.h` — автоматизированный фреймворк и тест-кейсы для проверки корректности работы

---
Проект содержит развитую систему автоматического тестирования, реализованную в tests.cpp. 
1. Тестируются цепочки отложенных вызовов ленивой последовательности: Append, Prepend, InsertAt, RemoveAt, Map, Where, Concat с верификацией промежуточных и финальных значений
2. Граничные условия и исключения: проверяется защита от отрицательных индексов, выходов за правые границы конечных последовательностей, а также поведение на пустых структурах данных с контролем генерации исключения IndexOutOfRangeException
Тестирование Машины Тьюринга:
1. Тест выполняет симуляцию перевода строки "AKMALOVA" в "DELIYA" по цепочке состояний
2. Защита от зависаний: эмулятор проверяется на зацикливание (правила движения каретки L -> R -> L)
3. Машина корректно останавливается по достижении лимита шагов
4. Фаззинг мусором: Автоматически генерируется 100 хаотичных правил переходов со случайными символами и состояниями. Тест подтверждает, что управляющий блок выдерживает некорректную логику без падения программы и утечек памяти
